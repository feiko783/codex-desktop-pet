# AgentPaw · AI 桌伴 1.9.8

1.9.8 修复授权提示卡片的样式与控件显示，统一桌面弹窗体验，并新增繁体中文与法语项目介绍。

## 授权与回答窗口

- 授权卡片沿用工作速览、行动中心的暖色圆角、边框、阴影与间距，标题和项目说明层次更清楚。
- 命令使用独立内容框；仅有允许与拒绝时并排展示，使用柔和的绿、红区分操作。
- 修复隐藏规则缺失导致的多余输入框、返回及提交回答按钮，以及浏览器默认控件外观。
- 补齐单选、多选、选中态、自定义输入与底部按钮样式。切换自定义回答时重新计算窗口高度，切换卡片时恢复输入提示。
- 长内容在卡片内滚动，窄窗口中的长项目名与命令不会横向溢出；屏幕上缘打开时保持卡片与桌面伙伴的正确排列。

## 四种语言的项目介绍

- 新增 [繁體中文 README](https://github.com/vista-zhangg/codex-desktop-pet/blob/v1.9.8/README_ZH_TW.md) 与 [Présentation en français](https://github.com/vista-zhangg/codex-desktop-pet/blob/v1.9.8/README_FR.md)，说明主要功能、安装与升级、数据隐私、许可证和角色素材署名。
- 四份 README 顶部统一提供简体中文、繁体中文、英文与法语入口。
- 本次新增的是文档语言，应用界面继续使用简体中文。

## 下载与升级

仅支持 **Windows x64**。下载 **`AgentPaw-1.9.8-Windows-x64.exe`** 安装升级，或使用应用内更新。`latest.yml` 由更新器读取，无需手动下载。现有配置、角色与本机用量记录继续保留。不提供 ZIP 便携包；Windows 安装包尚未进行商业代码签名。
